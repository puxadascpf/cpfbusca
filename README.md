## Sobre

O **CPF Buscas** é uma plataforma privada de consultas com **painel**, **histórico organizado**, **assinatura mensal via Pix** (liberação após a confirmação) e **API REST** para integração. São **62 módulos**: CPF, CNPJ, nome, telefone, placa, endereço/CEP, relações, localização, financeiro, fotos, OSINT e mais.
